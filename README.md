# Simple-Calculator
Simple Calculator made using Visual Studio and Windows Forms, written on C#

Instructions:

- X2 Button can only deal with one number at a time for now
  This means you cannot enter a calculation and use the "X2", so no = 5 + 5; 123 / 23;
  The button works only on one number at a time, so = 5; 5325; 2222; 40; As long as there are no calculation signs.
- If you encounter Error, the "Error Massage" will appear, after reading make sure to press AC in order to clear the field.

# Simple-Calculator

Einfacher Taschenrechner, erstellt mit Visual Studio und Windows Forms, geschrieben in C#

Anleitung:

* Der X2-Button kann momentan nur mit einer Zahl gleichzeitig arbeiten.
  Das bedeutet, dass Sie keine Rechnung eingeben und anschließend „X2“ benutzen können, also z. B. = 5 + 5; 123 / 23;
  Der Button funktioniert nur mit jeweils einer Zahl, also z. B. = 5; 5325; 2222; 40; solange keine Rechenzeichen vorhanden sind.
* Falls Sie auf einen Fehler stoßen, wird die „Error Massage“ angezeigt. Nachdem Sie sie gelesen haben, stellen Sie sicher, dass Sie AC drücken, um das Feld zu leeren.
